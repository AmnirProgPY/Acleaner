# Acleaner

A high-performance system cleaning utility built with Pythonand XAML.

## Architecture

- **Python**: Main application logic, UI handling, and orchestration
- **XAML**: UI definition for Windows Presentation Foundation

## Features

- [x] System junk file cleanup
- [x] Browser cache and history cleaning
- [x] Registry issue detection (Windows)
- [x] Duplicate file finder
- [x] Disk space analysis
- [x] Secure file deletion
- [x] High-performance C extensions for scanning

## Installation

```bash
# Clone repository
git clone https://github.com/AmnirProgPY/Acleaner.git
cd ccleaner-clone

# Install Python dependencies
pip install -r requirements.txt

# Run application
python src/main.py
